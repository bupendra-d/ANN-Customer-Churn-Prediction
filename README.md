# ANN Customer Churn Prediction

A beginner-friendly deep learning project that predicts customer churn using an Artificial Neural Network (ANN) built with TensorFlow and Keras.

### Features
- Data cleaning and preprocessing
- Label Encoding, One-Hot Encoding, and StandardScaler
- ANN model implementation using TensorFlow/Keras
- Early stopping to help prevent overfitting
- Interactive prediction interface built with Streamlit

### Tech Stack
Python · Pandas · Scikit-learn · TensorFlow/Keras · Streamlit
